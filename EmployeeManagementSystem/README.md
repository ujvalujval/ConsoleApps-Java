# Employee Management System

This directory contains the core source code for the Employee Management System, a Java console application for managing employee records.

## Features

- Add, update, and delete employee records
- View all employees or search by specific attributes
- Store and retrieve employee information using text-based persistence
- Simple, menu-driven user interface

## Structure

- `Employee.java` — Employee class and model
- `EmployeeManager.java` — Handles CRUD operations for employee records
- `Main.java` — Entry point with the main menu and program logic
- Other supporting files for utilities and data handling

## Getting Started

1. **Compile all Java files**  
   Run:
   ```
   javac *.java
   ```

2. **Run the application**  
   Run:
   ```
   java Main
   ```

## Requirements

- Java Development Kit (JDK) 8 or above

## Usage

Follow the on-screen menu to manage employee records.  
You can add, view, update, or delete employee information as required.
